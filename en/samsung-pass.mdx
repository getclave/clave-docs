Samsung Pass is Samsung's built-in password manager that provides secure authentication using biometrics and passkeys. For Clave users with Samsung devices, you need to set Samsung Pass as your preferred passkey provider.

## Setting Up Samsung Pass as Your Passkey Provider

Follow these simple steps to configure Samsung Pass for use with Clave:

1. **Go to Settings:** Open the Settings app on your Samsung device

2. **Search for Passkeys:** Use the search function at the top of Settings and type "passkeys"

3. **Tap "Passwords, passkeys, and autofill":** Select this option from the search results (the exact name may vary slightly depending on your device)

4. **Set Samsung Pass as Preferred Service:** In the "Preferred service" section, select **Samsung Pass** as your passkey provider instead of Google or other options

## Using Samsung Pass with Clave

When creating your Clave account or logging in:

1. **Account Creation:** During the account creation process, when prompted to save your passkey, Samsung Pass will appear as an option
2. **Biometric Verification:** Use your configured biometric method (fingerprint, face, or iris) to authenticate
3. **Passkey Storage:** Your Clave passkey will be securely stored in Samsung Pass
4. **Future Access:** For subsequent logins, Samsung Pass will automatically prompt you to use your stored passkey

## Benefits of Using Samsung Pass with Clave

- **Seamless Integration:** Native Samsung ecosystem integration
- **Enhanced Security:** Hardware-backed security features
- **Biometric Authentication:** Quick and secure access using your biometrics
- **Automatic Sync:** Passkeys sync across your Samsung devices signed into the same Samsung account

## Troubleshooting

If you encounter issues with Samsung Pass and Clave:

1. **Ensure Samsung Pass is Updated:** Check for updates in the Galaxy Store
2. **Verify Biometric Setup:** Make sure your biometrics are properly configured
3. **Check Passkey Settings:** Ensure passkey support is enabled in Samsung Pass settings
4. **Clear Cache:** If experiencing issues, try clearing Samsung Pass cache in device settings

For additional help with account creation or login issues, visit our [troubleshooting](./troubleshooting) page.
